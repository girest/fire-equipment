# 甲種第4類・乙種第4類：教材範囲・確認状況

## 公開版の学習範囲

- 共通：消防関係法令（共通・第4類）、電気基礎、感知器・発信機・受信機・音響装置、ガス漏れ警報、配線・回路、構造機能の規格、点検と整備、鑑別（文字回答、独自模式図）。
- 甲4のみ：工事、警戒区域、感知区域の配置、回路図、製図（独自模式図と自己採点）。
- 甲4：93解説・258問、うち筆記45＋鑑別5＋製図2の固定模擬試験を2セット。
- 乙4：89解説・240問、うち筆記30＋鑑別5の固定模擬試験を2セット。
- 甲乙は共有問題を含み、データ上の第4類固有問題は258問。

## 出題方針

- 消防試験研究センターの公式公開問題を出題**形式**の参考にしました。公開問題の文章や写真は転載していません。
- 四択の誤答は、可能な限り同じ領域の似た制度や規格・数値・技術用語を用いたオリジナル設問です。
- 計算問題では式・単位・途中過程を説明します。記述・製図は模範解答と照合して自己採点します。
- 問題データの `reviewStatus` が draft のものは、専門家監修済みとは見なせません。

## 検証済み（機械的）

`python tools/validate_content.py` により、問題ID、教材リンク、選択肢、正答の範囲、画像ファイル、模擬試験内の重複、正式な科目ごとの問題配分を検証します。`node --check` でJS構文を確認します。

## 未検証・今後の改善

- 全法令と技術規格の条文逐条照合・専門家監修は未了です。更新時に必ず公式資料を再確認してください。
- 実物写真による鑑別の学習は不足しています。著作権のある試験問題画像の転載はしません。
- 製図の配置は簡略化した図面を用います。筆記答案の自動採点、手描き添削、法令上の実施設計への適用は行いません。
- 本試験の難易度を統計的に検証したものではなく、合格を保証する教材ではありません。
- GitHub Pagesへの実公開・端末のオフライン実機テストは未完了です。公開後のテスト項目はREADMEを参照してください。

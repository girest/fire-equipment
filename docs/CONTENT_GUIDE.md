# コンテンツ設計と編集ルール

## データの分け方

- `qualifications` は `src/catalog.js` で管理します。
- 複数の資格に共通する法令・電気・機械は教材の**単一パック**で共有します。
- `audiences`（例：`["ko4", "otsu4"]`）で対象資格を明示します。
- 各教材の `id` は公開後変更しないこと。回答履歴のキーや解説リンクに使われます。
- 乙6の旧HTMLからの移行で、重複していた `gas` は `gas-laws` / `gas-agent` に分割しました。

## 解説 JSON

```json
{
  "id": "example-lesson",
  "group": "electric",
  "title": "オームの法則",
  "lead": "電流・電圧・抵抗の関係を説明する。",
  "parts": [["電圧", "電位差であり、単位はV。"], ["例", "V＝IR の例題を書く。"]],
  "questions": ["F4Q0040"],
  "refs": [{"label": "根拠", "url": "https://example.com/"}],
  "audiences": ["ko4", "otsu4"],
  "reviewStatus": "draft"
}
```

## 問題 JSON

```json
{
  "id": "F4Q0040",
  "type": "choice",
  "domain": "basic",
  "category": "電気の基礎",
  "prompt": "12Vを6Ωに加えたときの電流は？",
  "options": ["0.5A", "2A", "6A", "72A"],
  "answer": 1,
  "explanation": "V＝IR より I＝12÷6＝2A。",
  "lesson": "ohms4",
  "source": "電気の基礎知識",
  "url": "",
  "audiences": ["ko4", "otsu4"],
  "reviewStatus": "draft"
}
```

`answer` は**0始まり**（0,1,2,3）。`type: "written"` の場合は `options: []` と `answerText` を持ち、自己採点で記録します。

## レビューの最低条件

1. 法令の対象・用途・面積・例外条件を明記。例外を省く場合は問題文で「特例なし」を明示。
2. 公式試験の科目構成・問題数を毎回照合。
3. 数値は出典と単位を明記し、代入前後の式を別に検算。
4. 四択の**正解が一つだけ**であることを検証。
5. 誤答選択肢も同じ分野のもっともらしい誤りとし、無関係な選択肢で水増ししない。
6. 問題・解説・正答の整合性を確認。初学者向けに専門語を定義。
7. 鑑別・製図の図版は著作権に注意し、自作か権利のある画像を使う。単純な模式図は実物写真と混同しない表示にする。
8. 「draft」→「reviewed」→「verified」は、根拠確認済みの根拠と日付を記録した上で行う。
9. 合格判定の表示は科目別の40%、全体60%、実技60%を満たすか確認し、記述自己採点で断定しない。

## 静的PWAとデータ

- 1ページの全資格データを無理に先読みしない。資格を選んだ時に関連パックだけを読み込む。
- オフライン保存ボタンで当該資格のJSONと図版をキャッシュする。
- ブラウザの `localStorage` 保存キーは `fire-equipment-study-v1`。将来変更するならマイグレーションを用意する。
- 深いURLは `#/lesson/ko4/ohms` 形式で GitHub Pages の404を避ける。
- 環境・バージョンに応じたPWAキャッシュの切替は `sw.js` で管理する。

## 第4類の共有パックと模擬試験

- `content/class4/lessons.json` と `questions.json` は甲4・乙4共通のファイル。`audiences` で対象資格を制限。
- `exams-ko4.json` は52問（筆記45問・鑑別5問・製図2問）×2セット。
- `exams-otsu4.json` は35問（筆記30問・鑑別5問）×2セット。
- 第4類の問題は `F4Q...`（四択）および `F4W...`（記述式）。自作模式図は `diagram` キーで相対ファイルパスを指定。
- 全問題に適切な `lesson` と `source`・`url` を設定し、問題から関連教材への移動を可能にする。
- 第4類の個別問題の解説には対応する教材から「基本用語・仕組み・例」を追って確認する折りたたみ欄を出す。
- 第4類の `content` は試作ジェネレーター `tools/seed_class4.py` では上書きしないこと。現在の正式な編集対象は JSON ファイル。
- PWAのキャッシュバージョン変更時には、過去のオフライン教材を再保存する必要がある。

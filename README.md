# 消防設備士 学習サイト（GitHub Pages・PWA）

静的ファイルだけで動く、消防設備士資格別の教材・問題集です。React・ビルド・サーバー側DBは不要です。現在の収録範囲は甲4・乙4・乙6。ほかの資格は目次のみ用意しています。

## 収録範囲（2026-11-12 作成版）

| 資格 | 解説 | 対象の演習問題 | 模擬試験（既存演習問題から選定） | 備考 |
|---|---:|---:|---|---|
| 甲種第4類 | 93項目 | 258問 | 52問×2セット（筆記45・鑑別5・製図2） | 電気基礎・消防法令・受信機・感知器・規格・工事・製図 |
| 乙種第4類 | 89項目 | 240問 | 35問×2セット（筆記30・鑑別5） | 甲4と共通教材を共有。製図は非表示 |
| 乙種第6類 | 74項目 | 273問 | 35問×4セット（筆記30・鑑別5） | 既存教材を維持。逐条監修は未完了 |
| その他の甲乙10区分 | — | — | — | 目次のみ。未作成 |

甲4・乙4は共通教材を共有するため、両者の問題数を足しても別々の498問があるわけではありません。第4類の独立問題データは**258問**、乙6は**273問**、合計**531問**です。模擬試験は演習問題から科目数に合わせて抽出しているため、別途の新規問題を加算するものではありません。

第4類の解説は、基本用語・仕組み・使用例・混同しやすい点・解き方の5段階を基本に、補足解説と計算過程を加えています。独自の模式図は計12種類。鑑別24問と甲4専用の製図18問は記述式です（製図は実図面への筆記添削を自動評価するものではなく、模範解答と自己比較する形式）。

**学習上の注意：** 教材を「全科目が読める・練習できる」状態へ拡充しましたが、全問題の法令・技術規格との逐条照合、実物写真での鑑別、本試験と同一水準の難易度検証、専門家の監修は完了していません。公式過去問を転載していません。このサイト単独での合格は保証できません。施工手順書・法令遵守の判断資料には使用しないでください。

## GitHub Pagesへの公開

1. 新規リポジトリを作成。例：`fire-equipment-study`。
2. このプロジェクトフォルダの**中身**をリポジトリ直下に配置して `main` にpush。
3. GitHub → **Settings → Pages → Build and deployment → Source: GitHub Actions**。
4. `.github/workflows/pages.yml` が静的ファイルのチェックと公開を実行。Actionsの完了後に表示されたURLで開きます。
5. スマホのブラウザで一度サイトを開き、ホーム画面に追加するとアプリのように起動できます。
6. 利用する資格の概要ページで **「この資格をオフライン保存」** を押すと、その資格のJSON教材と図版を端末内キャッシュへ保存します。

**既存のリポジトリを更新する場合**も、公開ルートへ各ファイルを上書きする形でpushしてください。`content/otsu6/` は旧教材を残しています。公開後に学習履歴を復元するには「設定」→「進捗をJSONで書き出す／復元」を使います。

## ローカル動作の確認

```bash
python -m http.server 8000
# ブラウザで http://localhost:8000/ を開く
python tools/validate_content.py
node --check src/app.js
```

`file://` で `index.html` を直接開く方式では、JSONモジュール・PWAが動かない場合があります。HTTPサーバーまたはGitHub Pagesを利用してください。

## 機能

- 資格別の学習、分野別の解説・問題、検索、正誤の記録、ブックマーク・誤答復習
- 初学者向けの解説と元の問題との相互リンク
- 甲4・乙4の各2セット＋既存乙6の4セットの固定模擬試験。甲4は各52問、乙4は各35問
- 筆記問題は採点終了後に正解・解説を表示。鑑別・製図は模範解答を見た後に自己採点
- PWA、オフラインキャッシュ、ローカル進捗保存、JSONバックアップ、スマートフォン対応

解答はブラウザの `localStorage` に保存します。自動の端末間同期はありません。ブラウザのサイトデータ削除で記録が消えるため、バックアップしてください。キャッシュは内容更新に伴って切り替わるので、更新後はオンラインで開き直し、必要な資格のオフライン保存をやり直してください。

## フォルダ構成

```text
index.html / styles.css / manifest.webmanifest / sw.js
src/app.js              画面と演習
src/catalog.js          全13区分・教材パス
content/class4/         甲4・乙4共通教材、資格別模擬試験
content/otsu6/          以前の乙6教材（移行データ）
assets/diagrams/class4/ 独自SVG模式図
assets/icons/           PWAアイコン
.github/workflows/      GitHub Pages自動公開
docs/                   教材管理・今後のロードマップ
tools/validate_content.py 形式とリンクの自動チェック
```

コンテンツデータの仕様は `docs/CONTENT_GUIDE.md` を参照してください。`id` や `audiences` を不用意に変更すると既存の進捗履歴が切れるため、教材改修時はIDを保持します。
